\begin{question}{68}
투자가 실질 이자율에 의해 결정되는 폐쇄경제 IS-LM 모형에서 기대 인플레이션이 상승할 때 나타나는 결과로 옳은 것은? (단, IS곡선은 우하향, LM곡선은 우상향한다.)
\begin{choices}
  \item 명목 이자율과 실질 이자율이 모두 상승한다.
  \item 명목 이자율과 실질 이자율이 모두 하락한다.
  \item 명목 이자율은 하락하고, 실질 이자율은 상승한다.
  \item 실질 이자율은 상승하고, 생산량은 감소한다.
  \item 실질 이자율은 하락하고, 생산량은 증가한다.
\end{choices}
\end{question}
\answer{5}
