표의 경제모형에서 한계수입성향이 0.1로 감소하면 (ㄱ)\uline{균형국민소득과 (ㄴ)순수출} 각각의 변화로 옳은 것은? (단, $Y$는 국민소득, $C$는 소비, $I$는 투자, $X$는 수출, $M$은 수입이다.)
\begin{framedtext}
$Y=C+I+X-M$ \par
$C=100+0.6Y$\quad $I=100$\quad $X=100$\quad $M=0.4Y$ \par
\end{framedtext}
\begin{choices}
  \item ㄱ: 증가, ㄴ: 증가
  \item ㄱ: 감소, ㄴ: 증가
  \item ㄱ: 증가, ㄴ: 감소
  \item ㄱ: 감소, ㄴ: 감소
  \item ㄱ: 불변, ㄴ: 증가
\end{choices}
\end{question}
\answer{1}
