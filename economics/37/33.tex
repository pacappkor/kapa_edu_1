\begin{question}{73}
중앙은행이 아래와 같은 필립스곡선 하에서 손실을 최소화하도록 인플레이션율을 결정한다. 중앙은행이 \uline{(ㄱ)일정한 규칙을 준수할 경우 최소 손실}과 \uline{(ㄴ)자유재량 정책을 따를 경우 최소 손실}은 각각 얼마인가? (단, 민간부문은 합리적 기대를 형성한다고 가정한다.)
\begin{framedtext}
○ $u_{t}=5-2(\pi_{t}-\pi^{e}_{t})$ \par
○ $L(\pi_{t})=u_{t}+0.5(\pi_{t})^{2}$ \par
(단, $u_{t},\pi_{t},\pi^{e}_{t},L(\pi_{t})$는 실업률, 인플레이션율, 기대 인플레이션율, 손실함수이며, $t$는 시점이다.) \par
\end{framedtext}
\begin{choices}
  \item ㄱ: 0, ㄴ: 2
  \item ㄱ: 2, ㄴ: 2
  \item ㄱ: 2, ㄴ: 5
  \item ㄱ: 5, ㄴ: 5
  \item ㄱ: 5, ㄴ: 7
\end{choices}
\end{question}
\answer{5}
