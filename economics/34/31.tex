\begin{question}{71}
A국 경제의 총수요곡선과 총공급곡선이 각각 $Y_d = -P + 8$, $Y_s = (P - P_e) + 4$이다. 기대물가($P_e$)가 2에서 4로 증가할 때, (ㄱ)균형소득수준의 변화와 (ㄴ)균형물가수준의 변화는? (단, $Y_d$는 총수요, $Y_s$는 총공급, $P$는 물가, $P_e$는 기대물가이다.)
\begin{choices}
  \item ㄱ: 2, ㄴ: 2
  \item ㄱ: -2, ㄴ: 2
  \item ㄱ: -1, ㄴ: 0
  \item ㄱ: -1, ㄴ: 1
  \item ㄱ: 0, ㄴ: 0
\end{choices}
\end{question}
\answer{4}
