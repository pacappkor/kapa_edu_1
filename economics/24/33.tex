\begin{question}{73}
A국의 총생산함수는 $Y=20 \sqrt { L }$, 노동공급함수는 $w= \sqrt { L }$라고 할 때, 노동시장에서의 균형노동량($L*$)은? (단, $Y$ 는 총생산, $w$ 는 실질임금, $L$ 은 노동량이며, 상품시장과 노동시장은 완전경쟁시장이다.)
\begin{choices}
  \item $L*=5$
  \item $L*=10$
  \item $L*=15$
  \item $L*=20$
  \item $L*=25$
\end{choices}
\end{question}
\answer{2}
